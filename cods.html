Bastidores do Código

Análise das Tags (HTML)

Header: Tag semântica que define o topo do site, agrupando logo e navegação.

Nav e UL/LI: Organizam os links em lista, essencial para criar o menu em grid.

Section: Isola o carrossel do restante do site, criando um bloco independente.

Div e Class: As divs agrupam elementos, enquanto as classes funcionam como etiquetas para o CSS e JS.

Engenharia de Estilos (CSS)

Display Grid: Divide o cabeçalho em colunas exatas, mantendo o alinhamento.

Position Absolute: Permite que os itens do slider fiquem empilhados um sobre o outro.

Z-Index: Controla a profundidade; o item ativo sempre ganha o maior valor para aparecer na frente.

Transition-Delay: Cria o efeito cascata, onde título e descrição entram em tempos diferentes.

Lógica de Programação (JS)

Variável active: Rastreia qual carro está visível (0, 1 ou 2).

ClassList: O JavaScript remove a classe 'active' do antigo e adiciona no novo para disparar a animação.

Operador Ternário: Lógica que faz o slider voltar ao início automaticamente ao chegar no fim.

DOM: Permite que o JS altere o HTML em tempo real.
